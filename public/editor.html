Moon: a BIBFRAME cataloging editor

Moon is a web-based cataloging editor for BIBFRAME 3.0.1, the Library of Congress model for library linked data, built for Arabic and English collections. Catalogers create Works, Instances and Items, import and export MARC 21, and link names and subjects to an authority file. Every published record gets permanent URIs, is available as JSON-LD, Turtle and N-Triples and through a SPARQL endpoint, and appears in a public catalogue readers can search.
